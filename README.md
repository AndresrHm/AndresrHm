## Sobre mí

Soy desarrollador de software y egresado de la **Universidad Nacional de San Martín — UNSAM**.

Me interesa crear aplicaciones útiles, escalables y con una buena experiencia de usuario. Disfruto trabajar tanto en el desarrollo de interfaces modernas como en la construcción de APIs, sistemas de autenticación y soluciones basadas en datos.

Actualmente, mi objetivo es seguir creciendo como desarrollador **Full Stack**, mejorar continuamente la calidad visual y técnica de mis proyectos y construir un perfil profesional que refleje mi evolución.

```text
Frontend  →  Interfaces modernas, accesibles y responsivas
Backend   →  APIs REST, autenticación y lógica de negocio

Objetivo  →  Crear productos completos, claros y mantenibles
```

# Proyectos destacados

## 📚 BookLibre

Aplicación para facilitar el préstamo e intercambio de libros entre usuarios.

BookLibre permite publicar libros, buscar ejemplares disponibles, realizar reservas, gestionar préstamos y calificar experiencias dentro de la plataforma.

### Frontend

Tecnologías principales:

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios

Funcionalidades principales:

- Registro e inicio de sesión.
- Búsqueda de libros con filtros.
- Ordenamiento y paginación.
- Detalle de cada libro.
- Gestión de perfil.
- Publicación y edición de libros.
- Administración de préstamos.
- Sistema de calificaciones y bibliokarma.

[Ver repositorio Frontend →](https://github.com/AndresrHm/BookLibre-frontend)

### Backend

API REST desarrollada con Kotlin y Spring Boot.

Características principales:

- Autenticación y autorización mediante JWT.
- Roles de usuario.
- CRUD de libros y usuarios.
- Gestión de reservas y préstamos.
- Sistema de calificaciones.
- Persistencia con PostgreSQL y MongoDB.
- Caché con Redis.
- Consultas y métricas mediante GraphQL.
- Configuración de servicios con Docker.

[Ver repositorio Backend →](https://github.com/AndresrHm/BookLibre-backend)

## 💰 Vaquita

Aplicación para organizar gastos compartidos entre grupos, amigos o compañeros.

El sistema permite registrar gastos, calcular saldos automáticamente y visualizar quién debe pagar o recibir dinero.

### Frontend

Tecnologías principales:

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- React Hook Form
- Recharts

Funcionalidades principales:

- Creación y administración de grupos.
- Registro de gastos compartidos.
- Cálculo automático de saldos.
- Gestión de deudas y pagos.
- Visualización de estadísticas.
- Administración de amigos.
- Carga de tickets.
- Autenticación de usuarios.

[Ver repositorio Frontend →](https://github.com/AndresrHm/vaquita-app-frontend)

### Backend

Backend encargado de gestionar la lógica de negocio, usuarios, grupos, gastos y saldos de la aplicación.

[Ver repositorio Backend →](https://github.com/AndresrHm/vaquita-app-backend)

## 🚗 Detección de autos en estacionamientos

Proyecto académico de bases de datos e inteligencia artificial.

La aplicación utiliza **YOLOv8** y el dataset **PKLot** para detectar automóviles en imágenes de estacionamientos y almacenar métricas relacionadas con la ocupación.

El proyecto combina procesamiento de imágenes, análisis de datos y persistencia de información.
